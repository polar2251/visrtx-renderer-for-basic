# Third-party software

Visrtx Renderer for basic uses the OVITO Python package (MIT) and its
bundled renderers. OVITO is developed by OVITO GmbH. See [OVITO license
information](https://www.ovito.org/manual/licenses/index.html) for the
complete list of component licenses and the corresponding Qt/PySide6
source instructions.

The application also uses [Python and Tcl/Tk](https://docs.python.org/3/license.html),
[PySide6 Essentials and Shiboken](https://doc.qt.io/qtforpython-6/licenses.html),
[NumPy](https://numpy.org/doc/stable/license.html), and
[Traits](https://docs.enthought.com/traits/traits_user_manual/license.html).
The OVITO window bridge uses [uiautomation](https://github.com/yinkaisheng/Python-UIAutomation-for-Windows)
and [comtypes](https://github.com/enthought/comtypes).
The launcher is built with [PyInstaller](https://pyinstaller.org/en/stable/license.html).
NVIDIA's display driver is installed separately through NVIDIA.
